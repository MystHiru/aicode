# 角色

角色决定 AI 用**什么身份**和你对话。一句话概括：角色负责「它是谁」，提示词片段负责「它遵守什么规则」，两者叠加成完整的系统提示词。

## 角色是什么

每个角色有两部分内容：

- **名称**：显示在角色列表里，方便切换识别。
- **身份提示词**：一段文字，描述这个角色的定位、语气和擅长方向。

当前选中角色的身份提示词会被放在系统提示词的最前面，优先级高于其他片段。所以换角色会明显改变 AI 的回答风格，但不会改动工具权限、执行环境这些设置。

## 在 App 里管理

**设置 → 角色** 列出所有角色，当前生效的一个带勾选标记。

- 点一行切换当前角色，新会话立即使用新身份；已经在进行中的会话保持原样，下一轮对话生效。
- 右上角「+」新建角色，填名称即可，身份提示词可以之后再补。
- 点已有角色可编辑名称、身份提示词与头像。
- 左滑删除。**至少要保留一个角色**，删到最后一个时会提示无法删除。

## 头像

角色头像可选，支持从相册选图并按方形裁切。没有设置头像时用应用图标代替，不会留空。

头像只影响设置页与聊天中的显示，不参与提示词。

## 与提示词片段的关系

内置的 `00-identity.md` 片段仍然存在，但系统提示词里的「身份」部分改由当前角色提供：

- 角色身份在前，其余片段（沟通、编码纪律、工具说明等）在后。
- 其他片段可以用「提示词片段」页的开关单独关掉，角色身份则通过切换角色来改变。

具体片段与加载优先级见 [自定义提示词](/guide/custom-prompts)。

## 存储位置

角色数据存在应用私有目录 `aicode/roles/` 下，索引是一个 JSON 文件，头像单独存成图片文件。不写进工作区，所以切换工作区不会影响角色；换手机时需要通过备份还原。
