# 聊天界面导览

这一页说明主界面上各个按钮和区域都是干什么的。

## 顶部标题栏

- **菜单按钮**（左上）：打开侧边栏，管理会话列表和浏览文件。
- **会话标题与模型名**：上面一行是当前会话名，下面一行是正在用的模型。
- **新建会话**：开一个新的对话。
- **Git 入口**：跳转到 Git 版本管理页。
- **终端入口**：跳转到终端页。

远程 SSH 模式下，标题栏下方会多一行：左侧是 SSH 连接状态（圆点加文字），右侧是当前会话的 token 累计（上箭头输入、下箭头输出）。本地模式不显示这一行。

## 侧边栏

点左上角菜单按钮，或者从屏幕左缘往右滑。顶部有「会话」和「文件」两个标签页。

### 会话页

会话按最后回复时间从新到旧排列，并按时间分组（今天 / 昨天 / 7 天内 / 30 天内 / 更早按月份）。置顶的会话单独放在最前面的「置顶」分组，卡片是浅蓝色背景。

短按切换会话，**长按弹出操作菜单**：

- **置顶 / 取消置顶**：置顶后固定排在最前。
- **重命名**：改会话标题，不影响排序。
- **导出**：导出这个会话。
- **删除**：会弹确认框，确认后删除该会话及其所有消息。

派生过子代理的会话，行尾会显示子代理数量和展开箭头，点开可以在下方看到它的子代理（**1.11.0 起**），详见[子代理](/guide/subagent)。

### 文件页

浏览当前工作区的文件，点文件打开代码编辑页（**1.11.0 起**），详见[文件浏览与代码编辑](/guide/files)。

侧边栏底部是「设置」入口。

## 输入框下方工具栏

从左到右：

- **模式按钮**：在 BUILD、PLAN、AUTO 之间循环切换，见[三种模式](/guide/modes)。
- **模型按钮**：显示当前模型，点击弹出选择弹窗。顶部有搜索框可以模糊筛选，模型按提供商分组，每行标注能力标签（`Image`、`Tools`、输入输出长度），点一下就切换。
- **工作区按钮**：显示当前工作区名，点击弹出工作区管理面板（见下）。
- **文件按钮**：上传文件作为附件，AI 可以读它的内容。
- **图片按钮**：上传图片作为附件。点击直接打开系统相册，可以多选。需要当前模型支持图片输入。
- **发送按钮**：AI 空闲时是普通发送；AI 正在工作时，输入框为空则显示停止按钮，有内容则显示橙色发送按钮（消息会排队）。

上传的附件会以预览卡显示在输入框上方，发送前可以移除。

滚动消息列表时，输入框区域会淡出到 40% 透明度以减少干扰，停止滚动后恢复。

## 工作区管理

点工作区按钮弹出的面板里可以：

- **切换工作区**：点一下即切换。如果当前有正在运行的 AI 会话或终端标签，会先弹确认框——切换会停止它们。
- **新建工作区**：输入名称创建，对应手机上一个独立文件夹。
- **添加本地目录**（本地模式）：把设备上已有的目录作为工作区。首次点击会显示风险确认弹窗（AI 会直接读写你的真实文件），可以勾选「不再提示」。只支持从「内部存储」或「SD 卡」选择文件夹，云盘之类的其它文件提供方不支持。
- **删除工作区**：内部工作区连同文件一起删除；通过「添加本地目录」加进来的外部工作区只解除关联，**不会删除目录内容**。

工作区是 AI 操作的项目根目录，AI 的代码读写和命令执行都被限制在当前工作区内。

## 斜杠命令

在输入框输入 `/` 会弹出命令菜单：

- `/status`：查看当前会话状态（token 用量、模型、模式等），结果以 AI 气泡输出。
- `/compress`：手动触发当前会话的上下文压缩。

命令在 AI 忙碌时会进队列，空闲后自动执行。命令文本会作为用户消息显示在对话里，并进入上下文。

## 消息队列

AI 工作时输入框仍然可用。输入内容后点橙色发送按钮不会打断当前任务，而是加入**待发送队列**：

- 队列面板显示在输入框上方，列出排队消息的序号和摘要。
- 当前一轮任务结束后，队列里的下一条自动发送，多条按顺序执行。
- 点「停止」会跳过当前轮，立即执行队列里的下一条。
- 每条消息右侧的 × 可以把它从队列移除。

::: warning 队列只在内存里
切换工作区或者进程被系统杀掉时队列会清空，重要的话别只放在队列里。
:::

## 回复与工具卡片

AI 生成回复时以**打字机效果**逐字显示，速度跟随模型的吐字速度自动调节。思考过程和工具执行输出保持实时显示，不受打字机影响；生成结束后内容立即补全。

工具调用的卡片会以淡入展开动画逐个出现。翻看历史会话时不会重播动画。

点工具卡片的标题栏可以折叠或展开，看「指令」和「结果」。**执行中默认收起只留一行状态**——这样 bash 之类刷屏输出时不会占满屏幕，需要看的时候点开即可，输出进行中会有跳动圆点提示。

卡片底部有时会多出一行「后台任务／子代理已结束」的提示（绿点=成功，红点=失败）。这是 AI 干活期间后台任务跑完了，系统把完成通知搭在它这一次工具结果里当场告诉它，AI 不用等这一轮结束就能接着处理。AI 空闲时后台任务跑完则照旧单独显示一条提示条。

## 回复下方的用量与耗时

AI 回复气泡下面那一行，除了复制、回退、更多按钮，右侧还会显示：

- **token 用量**：`↑` 是这次请求的输入 token，`↓` 是输出 token。
- **缓存命中率**（**1.11.0 起**）：数据库图标旁的百分比，是这条回复对应的请求里命中服务端缓存的输入占比。命中越高越便宜也越快。没命中缓存、或者渠道不返回缓存数据时不显示。该字段从 1.11.0 开始记录，旧消息看不到。
- **本轮总耗时**（**1.11.0 起**）：时钟图标旁的时间，只挂在一轮任务的最后一条回复下。从你按下发送算到 AI 收工，中间的工具执行、等待你点授权的时间都算在内。不到 1 分钟显示成 `12s`，更长显示成 `2:05`（分:秒）或 `1:02:05`（时:分:秒）。任务还在跑时不显示，收工后才出现。

整个会话、整个渠道的累计用量与缓存命中率在[Token 用量统计](/guide/token-stats)里看。
