# 软件权限

「设置 → 软件权限」集中管理 App 需要的系统级权限。权限状态在页面恢复时（包括从系统设置页返回）自动刷新，已授权的项点击后不会有反应。

后台保活、屏幕常亮、AI 完成通知、实时通知、授权审批通知这几个开关在[后台运行](/guide/background-run)页。

## 安装未知应用

显示当前是否已允许。未允许时点这一行会跳到系统设置里本应用的「安装未知应用」开关页，开启后才能安装 APK。

## 访问存储空间

显示当前是否已授权。未授权时点击会弹系统权限申请框，用于读写工作区文件与容器镜像。

如果权限已被永久拒绝（系统不再弹框），会有弹窗提示，点「去设置」手动开启。

## 忽略电池优化

显示当前是否已豁免。未允许时点击跳到系统的电池优化申请页，对本应用豁免省电策略，降低后台进程被杀的概率。

## 自启动管理

点击跳转到你设备厂商（小米、华为、OPPO、vivo、魅族等）的自启动管理设置页，允许 App 在开机或被系统终止后自动拉起。厂商设置页打不开或匹配不到厂商时，会回退到本应用的详情页。

这一项配合「后台运行保活」和「忽略电池优化」一起使用，能进一步降低后台被终止的概率——国产 ROM 的后台限制比较激进，若长任务经常被打断，建议三项都开启。

## Shizuku 授权

Shizuku 让本应用可以执行系统命令，是 AI 的 `Shizuku` 工具的前提。这一行显示当前状态：

- **未安装 / 服务未运行**：点击打开 Shizuku 应用，按其中的指引安装或启动服务。
- **未授权**：点击申请授权，在 Shizuku 弹出的授权框里选「允许」。
- **已就绪**：授权完成，AI 即可调用 `Shizuku` 工具。

从 Shizuku 应用返回本页时状态会自动刷新。用法与安全注意事项见 [Shizuku 工具](/guide/shizuku)。

## Root 权限

设备已 root 并授权本应用时，这一行显示「可用」，AI 才能使用 `Root` 工具（以 su 身份执行命令）。未检测到 `su` 时显示「不可用」，点击该行可重新检测。

Root 与 Shizuku 是两条独立的宿主命令通道，互不影响：

- **Shizuku**：以 adb shell（uid 2000）身份执行，需要 Shizuku 应用授权。
- **Root**：以 root（uid 0）身份执行，需要设备已 root 并允许本应用提权。

两条通道的权限规则不同，详见 [Shizuku 工具](/guide/shizuku) 与 [工具授权](/guide/permissions)。

## 悬浮窗（可选）

设置首页「通用」分组里的「悬浮窗」是可选装饰功能，默认关闭。

打开前需要先授予「在其他应用上层显示」权限，未授权时点击开关会跳到系统设置页。授权后再打开，聊天页会显示一个可拖动的小图标，用于快速回到对话；大小可在同一面板里调整。

它由一个前台服务承载，所以系统通知栏会常驻一条「悬浮窗运行中」通知。关掉开关即停止服务并移除通知。

::: tip 不装也不影响使用
悬浮窗只提供快捷入口，关闭时不影响任何 AI 功能。
:::
