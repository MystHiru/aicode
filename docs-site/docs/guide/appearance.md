# 外观与语言

「设置」首页点「外观主题」「背景图」或「语言」会弹出底部选择窗口，选择后立即生效并保存。

## 外观主题

面板里分三块：明暗模式、配色方案、莫奈取色。选择后不会自动关窗，便于连续对比多套配色。

### 明暗模式

三选一：跟随系统、固定深色、固定浅色。

### 配色方案

四套预设，深浅两种模式各自配好：

- **默认蓝**：App 默认的蓝色调。
- **咖啡**：暖赤陶色 + 米白纸感底。
- **石墨**：中性冷灰，颜色干扰最小。
- **森林**：低饱和绿。

色块外圈是该主题的页面底色、内圈是主色，预览会跟随当前明暗模式变化。

Git 泳道色、日志级别色、diff 增删的红绿属于功能标识，不随主题变化，避免同一含义在不同主题下颜色不一致。代码编辑器的语法高亮与终端配色也是各自独立的设置。

### 莫奈取色

开启后从系统壁纸提取配色，上方所选的配色方案不再生效（色块变灰）。默认关闭。

需要 Android 12 及以上系统；低版本设备上开关不可用，描述会直接提示。壁纸调色板由系统生成，不同手机厂商的取色结果差异较大，效果不满意关闭即可。

## 外观与主题

设置首页「主题」下方点「外观与主题」进入整页，所有选项即时生效。分三组：

### 颜色与主题

- **主题模式**：跟随系统 / 固定深色 / 固定浅色。
- **配色方案**：四套预设，深浅两种模式各自配好。
- **莫奈取色**：从系统壁纸提取配色。开启后配色方案不再生效，需要 Android 12 及以上。
- **色彩风格**：柔和、中性、鲜艳、表现力、彩虹、缤纷、单色、还原、内容。它按饱和度与色相变换整套配色，页面底色和卡片也会蘸一点主色，不只是按钮变色。
- **强色调**：单独指定主色（蓝、紫、粉、红、橙、黄、绿、青），或跟随主题。

### 界面样式

- **标准 / Miuix**：Miuix 用更大圆角、更粗标题和更松行高，贴近 MIUIX 观感。它只改版式与圆角，颜色仍跟随配色方案，所以切配色时整屏都会跟着变。
- **界面缩放**：85%~115%，用来整体调大或调小字号。

### 界面与效果

- **纯黑背景**：深色模式下把页面底色压到纯黑，对比更高也更省电。浅色模式下开关置灰并说明原因。

## 自定义背景图

可以设置一张全局背景，垫在所有页面内容下方，可调可见度：

- **选择图片或视频**：从系统相册选静态图片、GIF 动图或 MP4 视频。手机相册里的「动态照片」也能直接用，App 会取出内嵌的视频播放。取消选择或文件无法读取时，会保留原背景。
- **可见度**：滑块 0% 到 100%，实际映射到 0% 到 60%。背景画在内容下方、页面底色与卡片随之半透明，所以开到高位也不会盖住文字。默认 15%，拖动实时生效。
- **移除背景**：恢复默认纯色背景。

有背景时顶部栏、卡片与输入区会变成半透明磨砂面，弹窗和底部面板保留较高不透明度，避免文字压在画面上难以阅读。视频背景静音循环播放，不拦截触摸。

## 语言

可以跟随系统语言，也可以直接指定一种已支持的语言。

## 终端外观

终端的配色主题、字体、字号、光标样式是单独一套设置，见[终端](/guide/terminal#外观设置)。
