# 终端

聊天页顶部标题栏的「终端」入口进入终端页面：本地模式运行 PRoot 容器内的 shell，远程模式连接到远端服务器的 SSH shell。

## 标签栏

*   顶部标签栏展示所有打开的终端标签，过多时可横向滑动；**当前激活标签自动滚动到可视位置**（新增、切换标签均自动定位，无需手动寻找）。
*   标签内容为状态点（绿=运行中、灰=已结束）+ 标题；右侧 × 关闭标签，末尾「+」新建标签。
*   点击标签切换当前会话；关闭当前标签后自动切换到相邻标签。AI 执行命令产生的标签也显示在这里。

## 终端区域

*   黑底终端显示 shell 输出与输入光标，点击区域聚焦后可直接输入，支持长按选择复制文本。

## 终端设置与个性化

*   **顶栏设置按钮**：终端页右上角齿轮图标（或系统「设置 → 外观与语言 → 终端设置」）进入终端个性化面板：
    *   **配色主题**：内置 5 款经典极客配色方案（Termius Dark、Dracula、One Dark、Monokai、GitHub Dark），实时热更新到所有终端标签；
    *   **字体大小**：10sp ~ 22sp 连续滑块调节，并提供顶部实时预览卡片；
    *   **终端字体**：默认使用系统等宽字体，可点「导入」从手机存储选择 ttf / otf / ttc 字体文件（如 JetBrains Mono、Fira Code）；导入后会复制到 App 私有目录并出现在字体列表中，点选即切换，点 chip 上的 × 可删除；删除当前使用中的字体会自动回落系统等宽。字体仅影响终端渲染，不改变 AI 对话区；
    *   **光标样式**：支持方块（Block）、下划线（Underline）、竖线（Bar）样式切换。

## 辅助按键栏（Termius 风格）

*   底部为专为移动端设计的极客横滑辅助按键工具条：
    *   **控制键**：`ESC`、`TAB`、`CTRL`、`ALT`（激活时带高亮指示灯状态，支持单次与组合输入）；
    *   **方向键**：`←` `↑` `↓` `→`（支持长按连续发送，快速移动光标）；
    *   **常用快捷控制**：`C-c`（中断当前前台进程）、`C-d`（发送 EOF/退出）、`C-z`（挂起进程）、`C-l`（清屏）；
    *   **常用符号**：`|`（管道）、`~`（主目录）、`/`、`-`、`_`、`>`（重定向）、`:`、`$`、`"`、`'` 等。
