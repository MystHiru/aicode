# Token 统计 (Token Stats)

“设置”首页「系统」分组下的「Token 统计」入口（图标为柱状图），进入后查看每次 AI 调用的统计信息。数据从功能上线后开始逐次记录（历史调用无明细），实时刷新。

页面自上而下包含：

*   **周期切换**：顶部四个筛选标签——今天 / 近7天 / 近30天 / 全部。切换后下方所有卡片、图表与列表同步更新；「今天」的趋势图按小时粒度展示，其余按天粒度。
*   **概览卡片**：两行共 4 张卡片——总消耗（输入+输出合计）、请求次数、费用、缓存命中率。费用按 models.dev 单价估算（缓存读取按缓存价，无缓存价时按输入价 10% 估算；缓存写入按缓存写入价，无该价时按输入价 1.25 倍估算）；缓存命中率 = 缓存输入 ÷ 总输入。
*   **消耗趋势**：折线图展示周期内每天的输入/输出/缓存命中 token 消耗（蓝色=输入，橙色=输出，紫色=缓存），线下方半透明填充便于辨识重叠部分；左轴为 token 数（k/M 缩写）。时间轴按周期完整展开（近7天/近30天按天、今天按小时），无记录的天/小时补 0，调用集中在同一天时也能正常显示走势。
*   **渠道统计**：按 AI 提供商聚合，每行显示渠道名、调用次数、输入/输出消耗与占比进度条，按总消耗倒序。
*   **模型统计**：按模型聚合，每行显示模型名、总输出、调用次数与调用成功率，按总消耗倒序。
*   **调用记录**：每页 10 条、底部可翻页的调用明细表，左右滑动可查看全部字段——调用时间（年月日时分）、渠道、模型、思考强度（本次调用的档位，无档位模型显示 -）、状态码（success=成功 / error=失败 / cancelled=已取消）、输入、输出、缓存、缓存命中率（缓存输入 ÷ 总输入）、首字延迟（TTFB）、总耗时、预估费用（无单价模型显示 -）。首字延迟为首个内容事件（文本/思考/工具调用结果）到达 - 请求发出的时间，纯工具调用轮也统计。
*   **重置**：页面右上角垃圾桶图标，点击后弹窗确认，确认后清空全部调用记录（统计随之归零），不可恢复。
*   无调用数据时：概览卡片保留显示（值为 -）；消耗趋势区块不显示；渠道统计 / 模型统计 / 调用记录区块保留，卡片内显示「暂无数据」占位。
