# 文件浏览与代码查看

侧边栏顶部「文件」标签页用于浏览当前工作区的文件，点文件会打开独立的代码查看页。本地工作区与远程 SSH 工作区都支持，读取方式由当前模式自动决定。

## 浏览文件

「文件」页是**单层浏览**，不是缩进展开的文件树：

- 顶部是**面包屑**，从工作区根 `workspace` 开始逐段列出当前路径，点任意一段即可跳回该层。
- 不在根目录时，面包屑下方会出现**上一级**入口。
- 列表里目录排在文件前面，同类按名称排序。点目录进入下一层，点文件打开代码查看页。
- 浏览范围限定在工作区内，不能退到工作区之外。
- 切换工作区后会自动回到新工作区的根目录。

之所以用单层而非缩进树：侧边栏宽度有限，而项目路径往往很深，缩进到四五层后文件名就只剩省略号了。

## 列表刷新

本地工作区下，当前目录的变动会**自动刷新**——不限于 AI 改文件，你在终端里跑命令、或用其它 App 改动同样会被感知。它监听的是当前正在看的那一层目录，不递归整棵文件树，因此大仓库下也不会占用大量系统资源。

两个补充刷新时机：

- **每次打开侧边栏**会重读一次当前目录。
- 面包屑右侧有**刷新按钮**，可随时手动重读。

远程 SSH 工作区无法监听远程文件系统变动，**只能**靠上述两个时机刷新；发现列表与实际不符时点一下刷新按钮即可。

远程模式下目录读取要走网络，可能出现短暂的加载状态；读取失败会在列表位置显示具体原因。

## 代码查看页

点击文件后侧边栏收起，进入全屏的代码查看页：

- 顶部显示文件名与完整路径，左上返回，右上标注**只读**。
- 支持语法高亮，已内置 30 种语法：Kotlin、Java、Python、JavaScript/JSX、TypeScript/TSX、JSON/JSONC、YAML、Shell、Go、Rust、C/C++、C#、CSS、SQL、XML、HTML、Markdown、PHP、Ruby、Swift、Dart、Lua、Groovy/Gradle、Dockerfile、Makefile、INI/properties、.env 等。
- 几个映射约定：`.kts` 按 Kotlin，`.gradle` 按 Groovy，`.toml` 套用 INI 语法近似处理；`Dockerfile`、`Makefile`、`.env` 这类没有扩展名的文件按文件名识别。
- 未识别的类型按纯文本显示，不影响查看。
- 配色随应用主题深浅自动切换。
- 系统返回键可直接回到聊天页。

### 当前限制

- **只读**：这一版不提供保存。AI 也会用工具修改同一批文件，先不开放写入是为了避免双方互相覆盖。
- **文件大小上限 2 MB**：超过的文件会提示过大而不打开——内容需要整份读进内存，再大会明显卡顿甚至崩溃。
- 二进制文件不做特殊识别，建议只用来看文本与代码。

需要修改文件时，仍然让 AI 来改，或在终端里用编辑器。
