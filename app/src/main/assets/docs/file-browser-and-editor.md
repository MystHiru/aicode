# 文件浏览与代码编辑

侧边栏顶部「文件」标签页用于浏览当前工作区的文件，点文件会打开独立的代码编辑页。本地工作区与远程 SSH 工作区都支持，读写方式由当前模式自动决定。

## 浏览文件

「文件」页是**单层浏览**，不是缩进展开的文件树：

- 顶部是**面包屑**，从工作区根 `workspace` 开始逐段列出当前路径，点任意一段即可跳回该层。
- 不在根目录时，面包屑下方会出现**上一级**入口。
- 列表里目录排在文件前面，同类按名称排序。点目录进入下一层，点文件打开代码编辑页。
- 每行左侧是类型图标，右侧分两行：第一行是名称，第二行是最后修改时间（目录只显时间，文件还会在后面接经单位换算的文件大小）。
- 文件按类型显示不同图标：图片各格式共用一个图标，PHP、Java、Python、JavaScript/TypeScript、Go、Rust、C/C++、Kotlin 等主流语言用各自的彩色图标，其它可识别的代码/配置文件用统一的代码图标，其余为普通文件图标；目录用文件夹图标。
- 浏览范围限定在工作区内，不能退到工作区之外。
- 切换工作区后会自动回到新工作区的根目录。

之所以用单层而非缩进树：侧边栏宽度有限，而项目路径往往很深，缩进到四五层后文件名就只剩省略号了。

## 从对话里点开文件

除了侧边栏浏览，AI 在对话中引用代码时会把文件路径写成可点击的链接（形如带下划线的 `文件路径:行号`）。**点击这类链接会直接打开代码编辑页**，等同于在文件浏览器里点开该文件；若链接带了行号，打开后还会自动跳到并滚动到对应行。

- 支持工作区内文件（`~/workspace/...`）、AI 配置目录（`~/.aicode/...`）以及容器系统文件（`/etc/...`、`/root/...` 等），远程 SSH 工作区下同样可点开。
- 对话里指向普通网址的链接不受影响，仍用系统浏览器打开。
- 点到不存在的路径、目录或超过大小上限的文件时，编辑页会给出相应的加载失败或过大提示。

## 列表刷新

本地工作区下，当前目录的变动会**自动刷新**——不限于 AI 改文件，你在终端里跑命令、或用其它 App 改动同样会被感知。它监听的是当前正在看的那一层目录，不递归整棵文件树，因此大仓库下也不会占用大量系统资源。

两个补充刷新时机：

- **每次打开侧边栏**会重读一次当前目录。
- 面包屑右侧有**刷新按钮**，可随时手动重读。

远程 SSH 工作区无法监听远程文件系统变动，**只能**靠上述两个时机刷新；发现列表与实际不符时点一下刷新按钮即可。

远程模式下目录读取要走网络，可能出现短暂的加载状态；读取失败会在列表位置显示具体原因。

## 新建文件与文件夹

面包屑右侧依次是三个图标按钮：**新建文件**、**新建文件夹**、**刷新**。

- 新建的条目落在**当前所在目录**下，新建文件是一个空文件。
- 名称只能是单个条目名：含 `/`、`\`，或为 `.`、`..` 时确认按钮不可点——避免一不小心创建到别的目录去。
- 同名条目已存在、或目录不可写时会提示创建失败，不会覆盖原有文件。

## 长按重命名与删除

长按文件或文件夹行，从底部弹出菜单：

- **重命名**：只在同一目录内改名，不做跨目录移动；目标名称已被占用时提示失败。
- **删除**：文件直接删除；文件夹会**连同其中全部内容递归删除**，因此会先弹确认框。删除不进回收站，**无法撤销**，请谨慎确认后再操作。

面包屑上方的「上一级」入口不响应长按。两类操作在本地与远程 SSH 工作区都可用，完成后会自动重读当前目录。

## 代码编辑页

点击文件后侧边栏收起，进入全屏的代码编辑页：

- 顶部左上返回，右上依次是**撤销**、**重做**、**保存**、**设置**按钮。撤销/重做在没有可撤销或可重做的改动时置灰；保存按钮仅在有未保存改动时可点；点设置按钮进入**独立的编辑器设置页**（见下）。
- 打开 **Markdown 文件**（`.md` / `.markdown`）时，撤销按钮左侧会多出一个**预览切换**按钮：点一下切到渲染后的预览，再点一下切回源码，循环切换。预览与源码共用同一编辑状态，切换不会丢失未保存的修改。
- 导航栏下方有一条**文件名小栏**：靠左显示当前文件名（有未保存改动时名前加一个星号），靠右显示光标的**行:列**与**文件编码**（UTF-8）。小栏与导航栏、与下方编辑区各有一条分割线。
- **底部快捷符号栏**：横向滚动，最左是缩进（Tab）、光标左移、光标右移，其后是编程常用符号（括号、引号、运算符、`;` `:` `|` `&` 等），点一下就在光标处插入。软键盘弹出时符号栏会浮在键盘上方，其底色与编辑区一致。
- 支持语法高亮，已内置以下常用语法：Kotlin、Java、Python、JavaScript/JSX、TypeScript/TSX、JSON/JSONC、YAML、Shell、Go、Rust、C/C++、CSS、XML、HTML、Markdown、PHP、Lua。
- 映射约定：`.kts` 按 Kotlin 高亮。
- 未识别的类型按纯文本显示，不影响编辑。
- 配色采用 **VS Code 默认主题**（深色 Dark+ / 浅色 Light+），随应用主题深浅自动切换，编辑途中切换主题不会丢失未保存的内容。
- 左侧行号区有独立底色，与编辑区略作区分，便于定位；行号左侧留有少量间距。当前行高亮只落在正文区，行号区不高亮。切换行/列时高亮直接在目标行出现，不逐行滑动。
- 内容可向下多滚一段（底部留有额外空间），便于把最后几行顶到屏幕中部查看。
- 有未保存改动时，点返回或按系统返回键会先弹确认框，可选**不保存**或**保存并退出**。

### 编辑器设置页

点右上角设置按钮进入独立的设置页，改动即时生效并被记住、下次打开沿用：

- **字体大小**：滑块调节。
- **自动换行**：开启后长行折行显示，不再横向滚动。
- **显示缩进参考线**：在缩进层级处绘制竖向参考线，默认开启。
- **显示自动换行箭头**：自动换行开启时，在折行处画出换行指示箭头，默认关闭。
- **显示空白符号**：把空格、Tab 与换行等空白字符可视化，默认关闭。

### 保存与并发

- **保存即覆盖写回**：点保存（或返回时确认保存）会把当前内容整份写回文件，成功后提示「已保存」。
- **不做外部并发检测**：AI 工具或终端可能同时改同一批文件，保存会直接以编辑器里的内容覆盖，不会提示文件已被外部改动。若你和 AI 可能同时动同一个文件，建议先让一方改完再动手，避免相互覆盖。

### 其它限制

- **文件大小上限 2 MB**：超过的文件会提示过大而不打开——内容需要整份读进内存，再大会明显卡顿甚至崩溃。
- **二进制文件不支持**：打开时会嗅探文件开头，若识别为二进制（如图片、可执行文件、压缩包等）会直接提示「二进制文件，暂不支持打开」，不会将乱码当文本载入。
