# 检查点与撤销回滚

在 Agent 执行写入工具修改代码时，系统会自动捕获并记录变更前的文件快照，供后续回滚恢复。

## 触发方式

在聊天界面的任意一条**用户消息**左侧，提供有「撤销/检查点」图标。点击即可打开选定检查点的控制菜单。

## 3 大控制操作

- **恢复代码与对话**：将代码文件还原至此检查点之前的快照，并截断此节点之后的所有对话消息，将原 Prompt 填回输入框。
- **仅恢复对话**：保持当前代码不变，仅截断/删除选定节点之后的对话消息。
- **仅恢复代码**：仅将代码恢复至选定检查点之前的快照状态，保持对话历史不变。

## 局限性

- **Bash 命令修改**：在终端中直接通过 Bash 命令（如 `rm`、`mv`、`sed` 等）修改或删除的文件无法通过自动检查点精确恢复。建议结合 Git 进行版本控制。
