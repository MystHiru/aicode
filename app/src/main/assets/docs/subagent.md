# 子代理 (Subagent)

子代理（subagent）是一个特殊的会话：由主会话的 AI 通过 `task` 工具创建，相当于**替用户向一个新会话发消息**，子代理会像普通会话一样自动开始回复。子代理拥有独立上下文与完整工具能力，可以和主代理并行干活；用户也能随时点进去查看进度、自己发消息或暂停。

## 如何使用

在对话中让 AI 使用 `task` 工具，例如：

- 「派个子代理去审查 `app/build.gradle.kts`，把问题列出来」
- 「创建两个子代理，一个研究数据库迁移方案，一个调研 UI 组件库选型」
- 「让子代理独立实现 `sendFile` 功能并跑通测试」

AI 会先征求你的同意（权限弹窗），创建后立即返回子会话 id，**不阻塞主对话**；子代理在后台自动开始工作。

## 与普通会话的关系

| 能力 | 普通会话 | 子代理会话 |
|---|---|---|
| 用户查看/发消息/暂停 | ✅ | ✅（和普通会话完全一样的界面） |
| AI 替用户发消息 | ❌（只有用户能发） | ✅（创建者 AI 可替用户发） |
| 独立上下文与完整工具 | ✅ | ✅ |
| 主会话并行运行 | — | ✅ 可同时派多个，各干各的 |

## 侧边栏「子代理」页

侧边栏顶部有两个标签页：

- **会话**：主会话列表
- **子代理**：当前会话派生出的子代理列表（与主会话列表风格一致，运行中的显示绿色状态点）

点击子代理项即可切换到该会话查看完整过程——界面和普通会话一模一样，没有特殊按钮。回到主会话只需在「会话」页点选父会话即可。

## 子代理的异步回调

子代理完成后，主会话会收到一条后台通知（与终端异步回调同机制），主代理据此得知子代理已结束。`task` 工具支持多种操作：

- `task(action="read", id=...)`：读取指定子代理的最后输出
- `task(action="stop", id=...)`：主动停止指定子代理（已产出的内容保留）
- `task(action="del", id=...)`：删除指定子代理会话及其全部消息（运行中会先停止）
- `task(action="list")`：列出当前会话的全部子代理及状态

## 限制

- **最多同时运行 5 个子代理**：创建超限时 `task` 会报错，需要等某个子代理完成或先用 `task(action="stop")` 停止后再创建。
- 子代理不能嵌套创建子代理（其工具集中不含 `task`）。
- 子代理与主会话共用同一权限体系，需要授权的操作仍会弹出确认。
- 删除父会话时，其下的所有子代理会话会一并删除。
