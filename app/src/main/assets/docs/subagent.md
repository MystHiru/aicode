# 子代理 (Subagent)

子代理（subagent）是一个特殊的会话：由主会话的 AI 通过 `task` 工具创建，相当于**替用户向一个新会话发消息**，子代理会像普通会话一样自动开始回复。子代理拥有独立上下文与完整工具能力，可以和主代理并行干活；用户也能随时点进去查看进度、自己发消息或暂停。

子代理分两种：**默认通用子代理**（继承父会话的模型与全量工具）和**自定义子代理**（你自己定义提示词、模型、工具集，见下文「自定义子代理」）。

## 如何使用

在对话中让 AI 使用 `task` 工具，例如：

- 「派个子代理去审查 `app/build.gradle.kts`，把问题列出来」
- 「创建两个子代理，一个研究数据库迁移方案，一个调研 UI 组件库选型」
- 「派个只读调研 agent 去搞清登录流程」（若你定义了名为调研类的 agent）

AI 会先征求你的同意（权限弹窗），创建后立即返回子会话 id，**不阻塞主对话**；子代理在后台自动开始工作。

## 自定义子代理

一个 `.md` 文件定义一个子代理，放在两处之一：

- **全局**：`~/.aicode/agents/<name>.md`（跨项目共享，跨升级保留）
- **项目级**：`<项目根>/.aicode/agents/<name>.md`（随工作区走，可 git 追踪）

同名定义项目级优先（与技能、MCP 两级配置一致）。文件格式为 YAML frontmatter + 正文，正文就是该 agent 的系统提示词：

```markdown
---
name: researcher
description: 只读调研：大范围搜代码、查资料、汇总结论，不改文件
provider: DeepSeek
model: deepseek-reasoner
reasoningEffort: high
tools: [readFile, list, search, websearch, webfetch]
disallowedTools: [Bash, terminal]
inject: [base, projectRules]
---
你是代码库调研专家。先用 search 定位入口，再用 readFile 逐层确认，
结论里必须给出 `文件路径:行号` 引用，不确定的地方明说未核实。
```

### 内置的 Explore

首次启动会自动将内置的 **Explore** 子代理释放到 `~/.aicode/agents/explore.md`，开箱即可用：

- 用途：只读代码库探索——搞清某个功能/调用链怎么实现的、某处逻辑在哪、某个改动要碰哪些文件。
- 工具：只给 `readFile`、`list`、`search`、`websearch`、`webfetch`、`loadSkill`——**没有写文件与执行命令的工具**，因此不会改动任何东西，也不会触发权限弹窗。
- 模型：未指定，继承父会话。想给它换个便宜模型，在 `explore.md` 里加 `provider` / `model` 即可。
- 提示词：强调先搜后读、结论带 `文件路径:行号` 引用、区分「读到的」与「推断的」、不编造路径与行号。

它只在文件不存在时释放，所以你改过的内容不会被升级覆盖；删掉后下次启动会重新释放一份默认的。

### 派发时必须给足上下文

子代理看不到主会话的任何历史：你们聊过什么、主代理读过哪些文件、已经得出什么结论，它一概不知道。`task` 的 `prompt` 就是它拥有的全部信息。主代理的提示词已要求它在 `prompt` 里写清四件事：目标与完成标准、已知上下文（文件路径、已核实结论、已排除的方向、用户定下的选型）、边界（不该动哪些文件、不要提交）、期望产出形式。

反方向也一样：主代理只能读到子代理的**最后一条回复**，中间过程与工具结果它拿不到。你自己点进子会话时能看到完整过程，但主代理看不到。

### frontmatter 字段

| 字段 | 必填 | 说明 |
|---|---|---|
| `name` | 否 | agent 名，`task(agent="...")` 用它。省略则取文件名 |
| `description` | 建议 | 何时该派这个 agent。这段会注入主代理提示词，主代理靠它判断该不该派 |
| `provider` | 否 | 提供商，可写设置里看到的名称或 id。省略则继承父会话 |
| `model` | 否 | 模型名。省略则继承父会话 |
| `reasoningEffort` | 否 | 思考强度：`none`/`minimal`/`low`/`medium`/`high`/`xhigh`/`max` |
| `tools` | 否 | 工具白名单。**省略等于继承全量工具**（不是“无工具”） |
| `disallowedTools` | 否 | 工具黑名单，先于白名单生效。支持 `mcp__server__*` 通配 |
| `inject` | 否 | 要注入的提示词片段，见下表。省略用默认值 |

工具名写设置→工具授权里看到的名字（`readFile`、`writeFile`、`editFile`、`Bash`、`terminal`、`list`、`search`、`websearch`、`webfetch`、`todo`、`memory`、`loadSkill`、`askUserQuestion`、`sendFile`、`viewImage`、`manageMcp` 等）。`task` 永远被剔除——子代理不能嵌套派子代理。

### inject：可注入的提示词

| 取值 | 含义 |
|---|---|
| `base` | 子代理专用精简基线：工具用法、路径约定、安全与可信边界。不含模式切换、结尾总结等主代理专属规则 |
| `mainRules` | 主代理的完整静态规则基线（需要子代理行为与主代理完全一致时用，比 `base` 费 token） |
| `skills` | 可用技能清单（子代理可 `loadSkill`） |
| `memory` | 全局 + 项目记忆的摘要清单 |
| `projectRules` | 项目规则（`AGENTS.md` / `CLAUDE.md`） |

省略 `inject` 等于 `[base, skills, memory, projectRules]`。写 `inject: [none]` 则只给 agent 自己的提示词，不注入任何额外内容。

MCP 工具不需要单独注入说明：只要工具集里包含 `mcp__*` 工具，子代理就能直接调用；不想给就用 `disallowedTools: [mcp__*]` 全部禁掉。

### 在设置里查看

设置 → 子代理，按「当前项目 / 全局」分组列出已定义的 agent。点行进详情可看模型、工具集、注入项、定义文件路径与提示词正文；左滑行可删除定义文件。详情页为只读展示，修改直接编辑那个 `.md` 文件（可让 AI 帮你写）。

### 主代理如何知道要派哪个

已定义的 agent 会以「可用子代理 (subagents)」清单注入主代理的系统提示词（只含名称 + `description`，不含提示词正文）。任务与某个 agent 对口时，AI 会用 `agent="名称"` 按名派发；名字写错会报错并列出可用名，不会静默回退成通用子代理。你也可以直接说「用 researcher 子代理去查 X」指定。

## 与普通会话的关系

| 能力 | 普通会话 | 子代理会话 |
|---|---|---|
| 用户查看/发消息/暂停 | ✅ | ✅（和普通会话完全一样的界面） |
| AI 替用户发消息 | ❌（只有用户能发） | ✅（创建者 AI 可替用户发） |
| 独立上下文与完整工具 | ✅ | ✅ |
| 主会话并行运行 | — | ✅ 可同时派多个，各干各的 |

## 侧边栏里的子代理

侧边栏顶部有两个标签页：**会话** 与 **文件**。子代理不单占一个标签页，而是就地挂在它所属的会话下：

- 在「会话」页，凡是派生过子代理的会话，行尾会显示子代理**数量**与一个展开箭头。
- 点箭头展开，该会话的子代理会缩进列在它下方（运行中的显示绿色状态点）；再点一下收起。
- 点子代理项即切换到该会话，界面和普通会话一模一样，没有特殊按钮；长按同样可置顶/重命名/导出/删除。
- 回到主会话只需在「会话」页点选父会话。

没有子代理的会话行不会出现展开箭头。

## 子代理的异步回调

子代理完成后，主会话会收到一条后台通知（与终端异步回调同机制），主代理据此得知子代理已结束。`task` 工具支持多种操作：

- `task(action="read", id=...)`：读取指定子代理的最后输出
- `task(action="stop", id=...)`：主动停止指定子代理（已产出的内容保留）
- `task(action="del", id=...)`：删除指定子代理会话及其全部消息（运行中会先停止）
- `task(action="list")`：列出当前会话的全部子代理及状态

## 限制

- **最多同时运行 5 个子代理**：创建超限时 `task` 会报错，需要等某个子代理完成或先用 `task(action="stop")` 停止后再创建。实际上通常开 1-2 个就够，5 是硬限制而非推荐值。
- 子代理不能嵌套创建子代理（其工具集中不含 `task`）。
- 子代理与主会话共用同一权限体系，需要授权的操作仍会弹出确认。权限弹窗全局串行，多个子代理同时请求授权时会排队；想让某个 agent 完全不碰需授权的操作，用 `tools` 白名单只给只读工具。
- 删除父会话时，其下的所有子代理会话会一并删除。
- 自定义子代理的定义在创建子会话时读取；改了 `.md` 文件对已在跑的子代理不生效，对之后新派的生效。
